# TunerAI Pro — local agent (Windows)

Download **TunerAI-Agent.exe** from the [latest release](https://github.com/Boostenstiein/tunerai-agent-download/releases/latest) and double-click it once. It installs for your Windows user (no admin rights, no Node.js), starts with Windows, and lets [TunerAI Pro](https://app.tuneraipro.com) read the map open in your ECU software and write the changes you confirm.

- Nothing is written to the ECU until you confirm each change on your computer, and every written cell is read back.
- The agent only listens on your own computer (127.0.0.1).
- Each release lists the SHA-256 of the file so you can check your download.
